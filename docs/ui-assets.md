# UI 美術素材清單（交給 UX/UI）

> 由 `node scripts/make_placeholders.mjs` 依 `src/assets.ts` 產生，請勿手改。
> 目前畫面上的都是佔位檔（`public/assets/ph/<id>.svg`）。交件時用同名檔案取代；
> 若改成 .webp / .png，請同步改 `src/assets.ts` 的 `assetUrl`。

風格：2.5D 斜俯視、蠟筆手繪繪本風（簡報 v15）。語氣是慢下來、無壓陪伴。

| ID | 尺寸（px，@1x） | 用在 | 說明 |
|---|---|---|---|
| `logo` | 160×48 | 頁首 | 曦語 Whisper Trees 字標，蠟筆手繪感 |
| `tree-hero` | 720×400 | 樹的頁面頂部 | 2.5D 斜俯視的一棵行道樹與人行道，繪本風；日間版 |
| `tree-hero-night` | 720×400 | 樹的頁面頂部（夜間） | 同上夜間版，「樹木休息中」的氣氛 |
| `glow` | 96×96 | 微光、光點 | 一道微光／光點的圖示，柔和發光 |
| `capsule` | 96×96 | 時空膠囊卡片 | 時空膠囊（信封或種子膠囊） |
| `sapling` | 96×96 | 許願、地圖許願圖層 | 小樹苗；地圖上依澆水數放大 |
| `watering` | 96×96 | 澆水按鈕 | 澆水壺 |
| `empty-pit` | 96×96 | 空樹穴抽屜 | 空的樹穴（方形土坑） |
| `scan-tag` | 240×160 | 掃樹牌說明 | 公園處樹牌與 QR Code 的位置示意 |

共 9 項。建議另交 @2x。
