# 09 迷霧（探索）

2026-10-19 使用者核准。放在集章冊「探索」區的最上方（`src/features/stamps/ExploreSection.tsx` 的 `fog-slot`；2026-10-20 起探索不再是獨立分頁，`/explore` 轉址到 `/stamps?tab=explore`）；導覽列與集章冊見 [08 §10、§11](08-extensions.md)。

## 目的

讓「打卡」有看得見的累積：整個台北蓋著一層霧，每打卡一棵樹，那棵樹周圍的霧就散開一小塊。

## 決定

- **只有打卡過的樹會散霧**：打卡結果是 `success` 或 `farView`（[03](03-checkin.md)）。從地圖點進樹的頁面、許願、澆水都不算。同一棵樹只算一次（`treeId` 整串比對，`-001` 之類的後綴要保留）。
- **半徑 50 m**，集中在 `src/features/fog/fog.ts` 的 `FOG_RADIUS_M`。比打卡門檻（30 m + 精度加成）大，是為了讓清出的範圍在街道層級看得出來。
- **不存軌跡**：霧完全由「自己的打卡紀錄 + 樹的座標」現場推算，不新增任何要存的欄位，也不記錄走過的 GPS 位置。座標從 `/data/trees/{前綴}.json` 經 `findTree` 查（和樹的頁面共用同一份快取）。查不到座標的樹略過，不影響其他樹。
- **統計只用一個誠實的指標組合**：「已探索 N 棵樹周圍」，N 是座標查得到的不同樹數；有清出範圍時用大家有感覺的說法（`areaPhrase`，2026-10-20 第四輪批評 4：原本「約 0.02 平方公里」太冷）：不到 1 平方公里換算成足球場，「已探索 3 棵樹周圍，約 1 個足球場那麼大」（1 個足球場 = 105×68 m = 7,140 m²，`PITCH_M2`；一個清出的圓〔半徑 50 m〕約 1.1 個；< 10 個四捨五入到個位、< 100 到 5、其餘到 10；不到 0.75 個寫「不到一個足球場那麼大」），1 平方公里以上才寫「約 1.3 平方公里」。數字是圓聯集的面積（重疊的部分不重複計算）換算來的，不是量出來的精確值；`data-area` 仍是平方公里數字。`formatArea` 保留但畫面不再用。
- 只在自己的畫面看得到，不上排行榜、不分享。
- **打開時看你走過的地方**（2026-10-20 批評修正 E）：全市縮圖看不見 50 m 的光暈，打卡了卻沒有回饋。所以有清出範圍就框住它（最近放大到 16.5 級，單一棵樹也看得到光暈）；圓全部在 3 km 內就整片框起來，散得更開（跨好幾區）就只框「1.5 km 內圓最多的一帶」，並列取比較晚打卡的（`fogView`）。左下角的鈕在「看全市」與「回到我走過的地方」之間切換，要看全貌隨時看得到。
- **框外還有走過的地方**（2026-10-20 批評修正）：散得很開、只框了最密的一帶時，框外的樹會被藏起來。所以左下角多一顆「還有 N 處走過的地方 ›」（N = 框外的樹數，`fogView().outside`），按了把**全部**走過的地方框進來（`fogAllView`，不是看全市）；這時按鈕變成「回到我走過的地方」與「看全市」。三種看法 `focus`／`all`／`city`，按鈕由純函式 `fogActions(mode, view)` 決定；全部在框內時沒有這顆。
- **散開處有暖光**：圓外緣疊一圈 `--glow` 色（#f2c14e）的柔光（半徑 1.7 倍、中央不透明度 0.8、中段 0.6；2026-10-20 第四輪 X 由 1.5 倍、0.7、0.5 加亮，390 px 上只走過一處也是看得見的獎勵，仍是柔光不是橘圈），像提燈照出來的一圈，和繪本的暖色一致；中央仍是乾淨的底圖。光是畫在霧上、再挖圓，所以圓重疊也不會互相蓋住。純顯示，不影響統計。
- **還沒打卡就不載入地圖**：換成一張小的繪本風空狀態卡（佔位美術 `fog-empty`，見 `src/assets.ts`）：「霧還沒散開／打卡過的樹周圍，霧會散開。」，加「去找一棵樹」連到首頁地圖。
- **失敗要看得見**：有打卡紀錄但一棵座標都查不到（多半是網路）→「探索範圍暫時查不到」＋「再試一次」（`lib/trees.ts` 的前綴檔失敗不再被快取，重試才會真的重抓）；底圖樣式載入前出錯或 20 秒還沒好 →蓋在地圖中間的「底圖載入失敗」＋「再試一次」。座標查詢中顯示同高度的占位框「正在整理探索範圍…」。

## 做法

`src/features/fog/`

| 檔案 | 內容 |
|---|---|
| `fog.ts` | 純邏輯：`exploredTreeIds`、`clearedCenters`、`unionAreaKm2`、`clearedBounds`、`fogView`（打開時看哪裡）、`clearPixelRadius`；重用 `lib/nearby` 的 `circleRing` |
| `useFog.ts` | hook：讀 `state.checkins`，非同步查座標，回傳 `{ centers, count, areaKm2, loading, failed, retry }` |
| `FogMap.tsx` | `<FogMap height?: number \| string />`：依狀態顯示占位、錯誤卡、空狀態卡，或內部的 `FogView`（MapLibre 地圖） |

**霧怎麼畫：疊在地圖上的 canvas，不是地圖圖層。** 每個影格先把 canvas 塗滿半透明灰綠色的霧，再用 `destination-out` 把每個圓挖掉（柔邊的圓形貼圖縮放後貼上）。

為什麼不用「台北範圍多邊形挖洞」：MapLibre 的填色用 earcut 三角化，洞和洞重疊時會畫壞；要正確就得先算圓的聯集，專案沒有 turf／polygon-clipping，不為這個加依賴。canvas 疊色天生處理重疊，圓的邊緣是柔的，縮放時邊緣永遠清楚，幾百到上千個圓每個影格也只是幾百次 `drawImage`。

取捨：

- 地圖固定俯角 0、不能旋轉，所以「公尺 → 像素」只有一個比例（量地圖中心往東 100 m 的像素數）；全市範圍內誤差不到 1%。
- 霧是畫面層，不在 `map.getCanvas()` 裡；要截圖要用整個容器。
- 縮小看全市時 50 m 不到 1 px，畫面上的圓至少畫 14 px（`MIN_CLEAR_PX`，2026-10-20 第四輪 X 由 9 加大，縮小時走過的地方才看得見），只影響顯示，不影響統計。

地圖：用 `MAP_STYLE` 與 `MAP_LOCALE`；範圍限制在台北市外框（`TAIPEI_BBOX` 外加 0.04°）；有清出範圍就依 `fogView` 縮放（最大 16.5 級）；可拖曳、縮放，不能旋轉或傾斜。

測試用的標記：`fog-map`（地圖容器，只有有清出範圍時才有）、`fog-stat`（統計，`data-count`、`data-area`；空狀態卡裡也有，`data-count="0"`）、`fog-empty`（空狀態卡）、`fog-find-tree`、`fog-go-all`（還有 N 處走過的地方）、`fog-go-city`（看全市）、`fog-go-focus`（回到我走過的地方／探索範圍）、`fog-error`（`role="alert"`）、`fog-retry`、`fog-pending`；地圖實例在 `window.__fogMap`。

## 沒有打卡時

不畫地圖，顯示空狀態卡（見上）；統計「已探索 0 棵樹周圍」在卡片裡。座標還在查的時候，顯示同高度的占位框「正在整理探索範圍…」。

## 驗收

- [x] 沒有打卡：顯示空狀態卡「霧還沒散開／打卡過的樹周圍，霧會散開。」與「去找一棵樹」（點了到首頁），`fog-stat` 的 `data-count` 是 0，沒有載入地圖。
- [x] 打卡 N 棵不同的樹：每棵周圍 50 m 散開，`data-count` 是 N；同一棵打卡兩次、或 `farView` 與 `success` 各一次，只算一棵。
- [x] 相鄰很近、圓互相重疊的樹，清出的範圍連成一片，沒有殘留的霧或破洞（目視 450 棵東門周邊的樹）。
- [x] 資料裡沒有的樹編號略過，不報錯、不計入 N。
- [x] 面積是聯集：兩個圓心距 50 m 的圓，面積約為單圓的 1.61 倍，不是 2 倍（單元測試）。
- [x] 寬 360 px 沒有水平捲動。
- [x] 450 棵樹時每個影格重畫不拖慢拖曳（桌機 headless 目視）。
- [ ] iPhone Safari、Android Chrome 實機：拖曳、縮放順暢、霧的顏色在戶外亮度下看得清楚。
- [ ] 接進集章冊「探索」區後，從打卡成功回到這裡，霧即時散開（取決於頁面整合）。
- [x] 框外的走過的地方（2026-10-20，Playwright 390／360 px，Demo，種入大安 14 棵＋士林 1 棵）：打開框大安那一帶，左下角有「還有 1 處走過的地方 ›」與「看全市」；按下縮放到約 11.8 級（14 → 11.8）、按鈕變「回到我走過的地方」與「看全市」；沒有水平捲動。單元測試：`outside` 計數、全部在框內時為 0、`fogAllView` 框住全部、`fogActions` 在各模式的按鈕。
- [x] 不新增任何儲存欄位、Firestore 規則不用改（本來就沒動）。
- [x] 批評修正 E（2026-10-20，Playwright 390／360 px，本機，Demo 模式）：種入 6 棵相鄰的樹，打開就放大到約 16.5 級、暖光環繞散開處；種入跨士林與大安的樹（9 棵），打開時框大安那一帶（16.5 級），按「看全市」縮到約 9.7 級、鈕變成「回到我走過的地方」；擋掉 `/data/trees/*.json` 出現「探索範圍暫時查不到」，放行後按「再試一次」回到地圖；擋掉底圖樣式出現「底圖載入失敗」，放行後再試一次消失；空狀態與地圖兩種狀態 360 px 都沒有水平捲動，按鈕 ≥ 44 px。單元測試（`fogView`：沒有圓、單棵、3 km 內、散開取最密一帶、並列取最近打卡）。**暖光的顏色與「看全市」鈕沒有在實機戶外亮度下看過；`fog-empty` 是佔位美術。**
