## 兩個入口，一份資料

| 入口 | 給誰 | 主要畫面 |
|---|---|---|
| 市民端 `/` | 一般市民（**只限手機**） | 地圖、掃樹牌、樹的頁面、樹洞、許願澆水、集章冊（含探索與圖鑑）、我的 |
| 政府端 `/gov` | 公園處承辦（桌機） | 需求熱點、補種優先分數、案件狀態 |

**市民端只能用手機開**（2026-10-19 決定）：判斷依據是觸控為主的裝置（`pointer: coarse`，手機與平板）。桌機開市民端頁面會看到「曦語要用手機開」與該頁的 QR Code；網址加 `?demo=1` 進 Demo 模式才能在桌機試玩；桌機上市民端一律維持手機寬度（最寬 430 px）、置中顯示（`.phone-shell`，寬 600 px 以上才生效，手機上不影響）。政府端、發包商、GM、開放 API 是桌機工具，不受限制。

**App 內建瀏覽器**（2026-10-20 決定）：從 LINE、Threads、Instagram、Facebook、Messenger、微信、TikTok、X 點連結打開，或任何認不出名字的內建 WebView（iPhone 上沒有「Safari/」、Android 上有「; wv)」），市民端頂端都會出現提醒「請改用 Safari（Android：Chrome）打開曦語」，說明掃樹牌、定位、加到主畫面、Google 登入可能不能用，並依 App 給做法：LINE 有直接跳轉的按鈕（`openExternalBrowser=1`），其他是「右上角「⋯」→ 在 Safari 中開啟」加「複製網址」。可以關掉，這次瀏覽不再出現（`src/features/device/InAppNotice.tsx`，判斷在 `inAppBrowser()`）。

兩端共用同一份資料庫（Firestore，跨裝置即時同步；沒有設定 Firebase 時退回 localStorage，同一台電腦開兩個分頁會同步）。

### 市民端導覽（2026-10-19 決定）

底部 5 格，由左到右：**首頁**（地圖）`/`・**集章冊** `/stamps`・**［掃樹牌］**・**樹洞** `/journal`・**我的** `/me`。右上角是光點餘額（點了去 `/shop`）。**首頁是普通的一頁**（在首頁時 `aria-current="page"`）；中間浮出導覽列的實心綠色大圓鈕在每個分頁都是「掃樹牌」（2026-10-20 決定，取代「首頁／掃樹牌」會變的設計）：按了到掃描頁 `/scan`，在首頁、地圖上選了樹時帶著那棵樹當提示；**關閉掃描頁一律回首頁地圖 `/`**（不是上一頁）；掃成功照舊進樹的頁面。**探索併進集章冊**：`/stamps` 頂端有「集章／探索」兩區，探索區放迷霧地圖、新手任務、樹的圖鑑；`/explore`、`/codex` 轉址到 `/stamps?tab=explore`。子頁面（`/tree/:id`、`/shop`、`/scan`、`/wishes`）不顯示導覽，用返回連結。政府端、發包商、GM、開放 API 不在市民端導覽裡，也不從市民端連過去；集中在只有 Demo 模式才顯示的「Demo 切換台」`/demo-control?demo=1`，在那裡切換市民端與各後台。細節見 [08 §11](08-extensions.md)。

## Demo 路線（2 分鐘）

1. **地圖**（20 秒）：街景裡你的動物站在樹旁、附近的樹發光；點一棵樹飛到樹旁（2026-10-19 起市民端地圖沒有全市視角；「全市 16 萬棵樹、16,781 個候選空樹穴、大安每公里人行道的行道樹是文山的 2.6 倍」這句話在地圖上沒有地方放，要講只能口述或用政府端的優先分數說明；**待隊上決定要不要另外放回**）。
2. **掃樹牌**（30 秒）：在網頁裡打開相機，掃一塊真的樹牌（或印出來的樹牌），GPS 確認在樹旁，打卡成功。
3. **樹洞**（20 秒）：留一句話；畫面只顯示「這棵樹本週有 12 道微光陪伴」。再掃一次，看到上次留下的話（時空膠囊）。
4. **見縫插樹**（25 秒）：在附近的空樹穴許願，系統馬上判定「空樹穴，容易種」；澆水 +1。
5. **政府端**（25 秒）：熱點清單裡出現這筆，拉權重滑桿，清單重排；改成「已排程」，切回手機，進度更新。最後一句帶出 DLC（垃圾桶、路燈）。

## 技術選擇

- **前端**：Vite + React + TypeScript，部署為靜態網站（Cloudflare Pages 或 GitHub Pages，皆為 HTTPS；相機與定位只能在 HTTPS 下使用）。
- **地圖**：MapLibre GL JS，底圖用免金鑰的向量圖磚（例如 OpenFreeMap）。
- **掃碼**：zxing 系列函式庫（`@zxing/browser` 或 `html5-qrcode`）。樹牌照片用 OpenCV 解不出來、zxing 可以；iOS Safari 沒有 `BarcodeDetector`。
- **資料庫與登入**：Firebase（匿名自動登入、可選 Google；Firestore）+ `src/mock/` 的種子資料；沒有設定 Firebase 時退回 localStorage。介面集中在一個 `store` 模組。後台寫入限白名單帳號，其他人是本機示範覆寫層。見 [firebase-setup](../firebase-setup.md)。
- **資料前處理**：Python（uv）腳本，輸出到 `public/data/`。

## 設計方向

- 簡報 v15 定案：2.5D 斜俯視、蠟筆手繪繪本風（角色造型仍在設計中）。Demo 先用柔和的地圖配色，插畫只放在樹的頁面與樹洞。
- 語氣：慢下來、無壓陪伴。不用排行榜、連續登入、紅點催促。
- 模擬資料在畫面上用小標籤「模擬」標出。
