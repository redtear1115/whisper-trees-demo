# 05 見縫插樹：許願、澆水、進度

## 目的

市民說得出哪裡需要樹；許願與澆水數成為補種優先分數裡的「市民需求」，進度一路公開。

## P0

### 許願（在空樹穴）

- 從地圖點空樹穴 → 「在這裡許願種樹」。
- 選原因（可複選）：通學、等公車、太曬、散步路線、其他。
- 送出當下就給**可行性初審**：
  - 候選空樹穴 → 「空樹穴，容易種」。
  - 提醒：「資料顯示這裡沒有登錄的樹，市府會先到現場確認。」
- 同一個樹穴只有一筆許願，之後別人來是「澆水」。

### 澆水

- 每人每天每個許願 1 次，+1。以台北日曆日計算，由安全規則強制（`waterings/{uid}_{日期}` + `wishStats`）。
- 顯示總澆水數（模擬種子數 + 真實點擊）。

### 進度時間軸

狀態一條線：`已收件 → 會勘中 → 可種・已排程 → 已種植`，另有 `不可種`（必須附原因，例如地下管線、人行道寬度不足）。

狀態由政府端的白名單帳號改變（[06](06-gov-console.md)），市民端即時反映。

### 許願分頁

列出自己許的願與澆過水的願，各自顯示目前狀態。狀態有變化時卡片顯示「進度更新了」（不做推播），停留 4 秒算看過。「看過幾筆」只存在這台裝置（`seen`）；這台裝置沒有紀錄時，自己許的願以 1 筆（已收件）為基準，換手機登入也會提示政府新增的進度；別人的願不提示，第一次出現時記下當下筆數，之後新增的才提示（`src/features/wish/updates.ts`）。也列附近別人的願，可以直接幫它澆水。樹洞頁的分頁名稱與 `/wishes` 標題都是「許願」。由上到下：
1. **我許的願**（完整時間軸）。
2. **附近別人的願**（`wishes-nearby`）：人物位置（`useAnchor`，GPS 或 Demo 模擬位置）`NEAR.radiusMeters`（300 m，和地圖能移動的範圍一樣）內、不是自己許的願，近到遠（純函式 `nearbyWishes`，`src/features/wish/nearbyWishes.ts`）。每張是精簡的許願卡：「離你約 N 公尺」、路名、理由、狀態膠囊、澆水數、「幫它澆水」（一天一次，規則同上）與「在地圖上看」。先列 3 個，其餘按「看更多（還有 N 個）」。Demo 的示範許願也會出現（標「模擬」）。沒有位置時顯示「還沒有你的位置…」，附近沒有時顯示「附近還沒有別人許的願。」
3. **我澆過水的別人的願**：不在上面那一區的才列，沒有就不顯示這一區。

三區都沒有東西時只顯示空狀態卡（`wishes-empty`）。

## P1

- **在非樹穴位置許願**：在地圖任意位置長按 → 初審結果為「需會勘」。
- 許願圖層：地圖上以小樹苗圖示顯示，大小對應澆水數。
- **進度提醒**：自己許的願有沒看過的進度時（判斷同上，只算自己的願）：
  - 底部導覽「樹洞」右上角顯示數字（超過 9 顯示「9+」）。
  - 樹洞頁預設停在「許願」分頁；停在其他分頁時，上方出現提示條「你的許願有 N 筆新進度，點這裡查看」，點了切到「許願」。
  - 在「許願」分頁看過（卡片停留 4 秒）後，數字與提示條消失。

## P2

- 推播通知、多人合資認養、達標自動排入計畫。

## 不做

- 每日任務：違反「不用連續登入、不催促」的語氣。想補樹的入口是樹的頁面上的「這附近還缺樹？去許願」，不是任務。

## 模擬資料

- `src/mock/wishes.json`：Demo 街廓預先放 5–10 筆許願，涵蓋每一種狀態，至少一筆「不可種」並附原因。
- 澆水數、狀態變更都存在 store（localStorage）。

## 驗收

- [ ] 許願後立刻看到初審結果，並出現在「許願」分頁的「我許的願」。
- [x] 許願分頁列出附近別人的願（單元測試 `nearbyWishes.test.ts`；Playwright 360 px、Demo、本機後端）：分頁名稱「許願」；新使用者在東門示範位置看到 3 張附近的示範許願（約 71、149、155 公尺）與「看更多（還有 2 個）」；按「幫它澆水」變成「今天的水已經澆好了」與「謝謝你，它喝到水了。」，並跳出第一道光的慶祝；沒有水平捲動。**沒有實機；雲端模式沒驗。**
- [ ] 同一天第二次澆水被擋下，顯示「今天已經澆過了」。
- [ ] 政府端（白名單帳號）改狀態後，市民端在另一台裝置不用重新整理就更新（Firestore）；沒有設定 Firebase 時，同一台電腦的另一個分頁會更新（`storage` 事件）。
- [ ] 「不可種」一定有原因文字。
- [ ] 政府端（白名單帳號）更新某市民許的願後，那位市民的底部「樹洞」出現數字；進樹洞頁停在「許願」分頁，卡片顯示「進度更新了」，4 秒後數字消失。
- [ ] 同一個帳號換一台裝置登入：自己許的願若已有政府新增的進度，也會出現數字；只有「已收件」時不出現。
- [ ] 澆過水的別人的願，換一台裝置不出現提示點；之後政府再更新它，才出現「進度更新了」。
- [ ] 360 px 下數字徽章不擠壓導覽文字，提示條沒有水平捲動。
