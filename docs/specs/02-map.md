# 02 地圖（市民端首頁）

## 目的

一打開就看到「台北的樹在哪裡、哪裡缺樹」，並從地圖進到樹的頁面或空樹穴許願。

## P0

- **底圖**：MapLibre GL JS，免金鑰的向量底圖，柔和配色。
- **兩種模式**（2026-10-19 決定）：
  - **附近**（預設）：45° 俯視、建物拉高成立體方塊（2.5D），鏡頭只能在目前 GPS 位置半徑 300 m 內移動，人走動時範圍跟著移（移動超過 15 m 才更新，避免抖動）。沒有定位權限或 Demo 模式時，以東門的示範樹為中心。
  - **全市**：平面、可以看整個台北，用來看空樹穴分布與行政區差距。
  - 角度、半徑、縮放集中在 `src/config.ts` 的 `NEAR`。
- **樹木圖層**：16 萬棵樹的點位（資料見 [01](01-data-pipeline.md)）。縮小時降低密度或改成熱度，放大到街道層級才顯示單棵。
- **空樹穴圖層**：16,781 個候選空樹穴，用和樹不同的顏色、形狀，例如空心圓。
- **點選**：
  - 點樹 → 底部抽屜顯示樹種、樹高、胸徑，按鈕「去這棵樹」。從地圖點進來的不算打卡，打卡一定要掃樹牌（[03](03-checkin.md)）。
  - 點空樹穴 → 底部抽屜「在這裡許願種樹」（[05](05-wish.md)）。
- **我的位置**：按鈕定位，顯示藍點與誤差圈。
- **主要按鈕**：畫面底部固定一顆大的「掃樹牌」按鈕。
- **圖層切換**：樹木、空樹穴、許願（[05](05-wish.md)）、DLC 預告（[07](07-dlc-preview.md)）。

## P1

- **行政區差距卡片**：「大安區每公里人行道的行道樹，是文山區的 2.6 倍」，資料來自 `districts.json`。
- **公園範圍**：`parks_boundary.geojson` 淡綠色面（OSM 授權，要標註來源）。
- **地圖署名**：底圖、OSM、政府開放資料。

## P2（未來展望）

## Demo 街廓

預設東門市場周邊（「誤砍茄苳」事件），待隊上確認。若改用會場附近（北平東路），要選一棵能在現場掃的真實行道樹，見 [03](03-checkin.md)。

## 驗收

- [ ] iPhone Safari 與 Android Chrome 首次載入（4G 節流）5 秒內可操作。
- [ ] 放大到街道層級，點得到單棵樹，抽屜資料與 CSV 一致。
- [ ] 空樹穴和樹在顏色、形狀上都能分辨（不只靠顏色）。
- [ ] 寬 360 px 的手機沒有水平捲動。
- [ ] 附近模式拖曳或縮小都離不開 300 m 範圍；切到全市可以自由移動。
