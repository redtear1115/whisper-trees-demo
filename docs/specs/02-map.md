# 02 地圖（市民端首頁）

## 目的

一打開就看到「台北的樹在哪裡、哪裡缺樹」，並從地圖進到樹的頁面或空樹穴許願。

## P0

- **底圖**：MapLibre GL JS，免金鑰的向量底圖，柔和配色。
- **兩種模式**（2026-10-19 決定）：
  - **附近**（預設）：45° 俯視、建物拉高成立體方塊（2.5D），鏡頭只能在目前 GPS 位置半徑 300 m 內移動，人走動時範圍跟著移（移動超過 15 m 才更新，避免抖動）。沒有定位權限或 Demo 模式時，以東門的示範樹為中心。
  - **全市**：平面、可以看整個台北，用來看空樹穴分布與行政區差距。
  - 角度、半徑、縮放集中在 `src/config.ts` 的 `NEAR`。
- **轉方向**：手機兩指旋轉，桌機右鍵拖曳（Mac 也可按住 Control 拖曳，同時可傾斜）。右下角指北針顯示目前方向，點一下轉回北方（保留俯角）。
  - **手機**：附近模式有「方向」按鈕＝「跟著方向」：地圖隨手機指南針轉，畫面上方就是面向的方向（iOS 會先要求權限；手動轉地圖就停止跟隨）。按下後 2.5 秒內收不到方向資料（沒有指南針），改開下面的旋轉控制。
  - **桌機／沒有指南針**（`pointer: fine`，市民端桌機只在 `?demo=1` 進得來）：「方向」按鈕（兩種模式都有）改開小面板「旋轉地圖」：**左轉／右轉**各 15°（有動畫，連按會累加）、一個可以**拖曳的羅盤圈**（像 Google Earth：圈跟著指標轉，北方記號順時針移動，地圖方位角反向變化；也可聚焦後用左右方向鍵每次 5°），以及一行提示「右鍵拖曳或按住 Control 拖曳，也能旋轉和傾斜」。再按一次按鈕、按 ×、或按 Esc 關閉。指北針按鈕照舊可用。
  - 程式在 `src/features/map/RotationControl.tsx`（元件）與 `rotation.ts`（角度計算，有單元測試）。
- **人物感應圈**（附近模式）：以人物（藍點或 Demo 示範位置）為中心畫一圈柔和的微光圈，半徑 = **打卡的感應半徑** `checkinRadius(accuracy) = 30 m + min(accuracy, 30 m)`（[03](03-checkin.md)），打卡判斷與這個圈共用同一個函式，所以「圈內的樹」就是「掃了牌會成功的樹」。
  - Demo 模式用 `CHECKIN.demoAccuracy`（5 m）→ 半徑 35 m；真實 GPS 用定位回報的誤差，誤差變動 5 m 以上才更新。沒有定位（fallback）時不畫圈、不數樹。全市模式不顯示。
  - 圈內的樹用另一層較亮的樹點（淡綠加暖金邊）標出；數量由已載入的圖磚以距離計算（樹籍編號去重）。
  - 底部提示「附近有 N 棵樹可以掃」（N > 0 才出現，沒有紅點、沒有計數徽章）：放在原本「找一棵樹，掃它樹幹上的樹牌」那一行的位置，N = 0 時回到原文字，不佔新的空間。
  - 感應圈只是提示：打卡仍然一定要掃樹牌 QR Code，從地圖點樹不算打卡。程式在 `src/features/map/ring.ts`。
- **樹木圖層**：16 萬棵樹的點位（資料見 [01](01-data-pipeline.md)）。縮小時降低密度或改成熱度，放大到街道層級才顯示單棵。
- **空樹穴圖層**：16,781 個候選空樹穴，用和樹不同的顏色、形狀，例如空心圓。
- **點選**：
  - 點樹 → 底部抽屜顯示樹種、樹高、胸徑，按鈕「去這棵樹」。從地圖點進來的不算打卡，打卡一定要掃樹牌（[03](03-checkin.md)）。
  - 點空樹穴 → 底部抽屜「在這裡許願種樹」（[05](05-wish.md)）。
- **我的位置**：按鈕定位，顯示藍點與誤差圈。
- **主要按鈕**：畫面底部、底部導覽上方浮著一顆大的「掃樹牌」按鈕；右上角是光點餘額（[08 §11](08-extensions.md)）。
- **圖層切換**：樹木、空樹穴、許願（[05](05-wish.md)）、DLC 預告（[07](07-dlc-preview.md)）。

## P1

- **行政區差距卡片**：「大安區每公里人行道的行道樹，是文山區的 2.6 倍」，資料來自 `districts.json`。
- **公園範圍**：`parks_boundary.geojson` 淡綠色面（OSM 授權，要標註來源）。
- **地圖署名**：底圖、OSM、政府開放資料。

## 驗收

- [ ] iPhone Safari 與 Android Chrome 首次載入（4G 節流）5 秒內可操作。
- [ ] 放大到街道層級，點得到單棵樹，抽屜資料與 CSV 一致。
- [ ] 空樹穴和樹在顏色、形狀上都能分辨（不只靠顏色）。
- [ ] 寬 360 px 的手機沒有水平捲動。
- [ ] 附近模式拖曳或縮小都離不開 300 m 範圍；切到全市可以自由移動。
- [ ] 附近模式（Demo 或真實 GPS）有一圈微光感應圈，半徑等於 `checkinRadius`（Demo 35 m）；圈內的樹有亮色標示，底部顯示「附近有 N 棵樹可以掃」，N 和圈內亮色的樹數一致；沒有定位時沒有圈、沒有提示。
- [ ] 感應圈與打卡判斷共用 `checkinRadius`，單元測試涵蓋判斷的邊界（半徑內 0.5 m 成功、外 0.5 m 太遠）與圈半徑。
- [ ] 寬 360 px 時，「附近有 N 棵樹可以掃」不和掃樹牌按鈕、附近／全市切換、新手任務、地圖工具、導覽抽屜重疊。
- [ ] 桌機（`?demo=1`）按「方向」開旋轉面板：左轉／右轉各 15°、拖曳羅盤圈會轉地圖（順時針拖，方位角減少）、方向鍵可用、指北針仍能轉回北方；右鍵拖曳旋轉後不會誤開許願抽屜。
- [ ] 手機沒有指南針時，按「方向」2.5 秒後改開旋轉面板；有指南針時維持跟著方向。
