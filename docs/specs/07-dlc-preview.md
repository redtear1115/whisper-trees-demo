# 07 DLC 預告：垃圾桶、路燈

## 定位

垃圾桶與路燈是未來擴充的 DLC，沿用同一套「市民回報 × 後台營運 × 政府資料」。**Demo 不實作互動**，只讓人看得出這個方向。

## P1

- 地圖的圖層切換裡多兩個灰色選項：「垃圾桶」「路燈」，標「即將推出」（DLC 是遊戲用語，市民看不懂，畫面一律寫「即將推出」）。
- 點下去顯示一張說明卡，不開圖層：
  - **垃圾桶**：回報滿溢、依行人流量與通報熱點建議佈點（對應 debug 松題目 #2）。
  - **路燈**：回報故障。公園處的「行道樹路燈資訊網」本來就把行道樹和路燈放在同一個系統。

## P2

- 垃圾桶真實點位：[臺北市行人專用清潔箱](https://data.gov.tw/dataset/121355)，只顯示點，不互動。要先下載到 `material/raw/` 並更新 README 的資料表。

## 尚未確認

- 路燈上是否有類似樹牌的 QR Code 或編號牌。確認前，不要在畫面或簡報上寫「掃路燈打卡」。

## 驗收

- [ ] 兩個 DLC 選項看得出是預告，不會被誤以為壞掉。
