# 03 打卡：掃樹牌 QR Code + GPS

## 為什麼這樣做

- 公園處樹牌上**已經有 QR Code**，不用新增設施。
- 只靠 QR Code，翻拍就能打卡；只靠 GPS，不知道是哪一棵樹。**QR 證明是哪一棵，GPS 證明人在現場**，兩者合起來才算打卡。
- 不做 NFC：目前沒有 NFC 樹牌，也沒有驗證過。

## 樹牌 QR Code 格式（已確認）

```
http://trees.gov.taipei/show/?treeid=SL0560111023
```

以實拍樹牌解碼確認，照片為 `material/samples/tree-tag-SL0560111023.jpg`。

**一定要在我們的網頁裡掃**。用手機內建相機掃會開到公園處的頁面，不會進到我們的網站。

## 流程

1. 按「掃樹牌」→ 要求相機權限 → 開後鏡頭掃描（不用按快門）。
2. 解出字串 → 取 `treeid`：
   - 先試網址參數 `treeid`。
   - 不是網址時，在字串裡找 `[A-Z]{2}\d{10}(-\d{3})?`。
   - 都找不到 → 「這好像不是樹牌，再試一次」。
3. 依 `treeid` 前 2 碼載入查詢表（[01](01-data-pipeline.md)）→ 找不到 → 「資料裡還沒有這棵樹」（資料是 2026-10-16 的版本，新植的樹可能還沒有）。
4. 同時要求定位，取得 `latitude`、`longitude`、`accuracy`。
5. 算出和樹的距離 `d`，判斷：

| 結果 | 條件 | 畫面 |
|---|---|---|
| 打卡成功 | `d ≤ 30 m + min(accuracy, 30 m)` | 進樹的頁面，顯示「你在這棵樹旁邊」 |
| 遠觀模式 | 樹的 `RegionRemark` 是 `安全島`，且 `d ≤ 80 m` | 進樹的頁面，可看、可回報，不算近距離打卡（安全優先，不必走到安全島上） |
| 太遠 | 其他 | 「你離這棵樹約 N 公尺，走近一點再掃一次」，仍可以看樹的資料 |
| 無法定位 | 使用者拒絕或逾時 10 秒 | 「沒有位置就無法打卡」，仍可以看樹的資料 |

**感應半徑**只有一個定義：`checkinRadius(accuracy) = nearMeters + min(accuracy, maxAccuracyBonus)`（`src/lib/geo.ts`）。打卡判斷（`judgeCheckin`）與地圖「附近」模式的人物感應圈（[02](02-map.md)）都呼叫它，兩邊不會不一致。Demo 模式的模擬位置誤差是 `CHECKIN.demoAccuracy`（5 m）→ 半徑 35 m。地圖上圈內有樹只是提示，打卡仍要掃樹牌 QR Code。

門檻值集中放在設定檔，Demo 前依現場測試調整。

## Demo 模式（模擬 GPS）

現場會場不在 Demo 的樹旁邊，需要備案：

- 網址帶 `?demo=1` 時，定位改成**可以移動的模擬位置**（2026-10-19 決定），畫面角落顯示「Demo 模式：模擬定位」。
  - 預設站在示範樹 `DA0030211045` 的位置（`DEMO`），所以現場照舊：開 `?demo=1`、掃示範樹牌就成功。
  - 模擬位置存在這個瀏覽器分頁（sessionStorage，經 store 的 `getDemoPosition` / `setDemoPosition` / `useDemoPosition`；`exitDemoMode` 會清掉）。移動的方式見 [02 地圖](02-map.md)：拖曳人物，或點樹後的「走過去」。
  - **掃樹牌用模擬位置判斷**（`CHECKIN.demoAccuracy`，`judgeCheckin` 不變）：離樹太遠就是「太遠」，和真實使用一樣；走到樹旁（35 m 內）才成功；安全島樹的遠觀規則照舊，只是距離從模擬位置算。示範按鈕（「掃示範樹牌（Demo）」「掃這棵樹的樹牌（Demo）」）只是代掃，不再假裝站在樹旁。
- README 已註明這是模擬資料。
- **首選**：Demo 前找一棵會場（北平東路 30-1 號）附近的真實行道樹，拍下樹牌、印出來，現場掃。這樣 GPS 也是真的。

## 掃碼實作

- 用 zxing 系列函式庫（`@zxing/browser` 或 `html5-qrcode`）。iOS Safari 沒有 `BarcodeDetector`。
- 同一張樹牌照片，OpenCV 解不出來、zxing 可以，所以不要用其他解碼器。
- 也提供「從相簿選照片」，給不方便開相機的情況。
- 相機與定位只能在 HTTPS（或 localhost）使用。

## 防作弊（P2，只寫進未來展望）

- 同一棵樹一天只算一次打卡。
- 異常速度（兩次打卡距離 ÷ 時間不合理）標記。
- GPS 可以偽造，Demo 不處理。

## 掃描頁的提示（2026-10-19）

從地圖點樹後的「掃樹牌」圈（[02](02-map.md)）或樹頁面的「掃樹牌」鈕進來，路由 state 帶 `hintTreeId`：掃描頁底部多一行「要打卡的是：樹種・路名。找到它樹幹上的樹牌，對準 QR Code。」（`data-testid="scan-hint"`）；Demo 模式的示範按鈕變成「掃這棵樹的樹牌（Demo）」，掃的是這棵樹（沒有提示時照舊掃示範樹）。只是提示：掃到別棵樹、手動輸入編號都照常判斷，打卡判斷（`judgeCheckin`）不變。
